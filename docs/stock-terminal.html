个股 K 线箱体 + 行业 / 题材联动

输入任意美股代码，用你自己的 Tiingo EOD 数据在浏览器本地计算历史大/小箱体；再把个股与行业ETF、题材ETF放到同一结构视图。Token 不保存，个股行情默认只保存在本机浏览器 IndexedDB。

1. 载入个股

尚未载入个股。若浏览器直连 Tiingo 被跨域/网络阻止，可导入本地 JSON。

Windows 直连失败备用：下载本地个股 JSON 生成脚本（PowerShell）。脚本只在本机进程使用 Token，不把 Token 写入 JSON。

数据许可边界：本站不公开托管你的个股历史行情；箱体与评分均在浏览器本地计算。20日小箱体 / 60日大箱体规则与现有 Structure Lab 保持一致。

2. 行业 / 题材映射

载入个股后尝试自动映射；你可以手动覆盖。

行业映射优先使用 Tiingo Fundamentals 元数据；题材属于研究标签，按公司行业/描述关键词启发式匹配，并允许手动覆盖，不声称是官方分类。

正在读取你已经保存的 29 ETF Bundle，作为行业/题材上下文。

3. 个股主图 / 历史箱体

等待个股行情。

4. 个股 / 行业 / 题材三层联动

比较层只描述结构、活跃度与相对强弱，不自动生成买卖建议。题材活跃度延续是已验证的状态特征，但不等于未来价格上涨。

5. 历史箱体编号与评分

形成度、稳定度越高越好；交易难度越高表示箱体内部越嘈杂；综合分是结构描述，不是收益预测。点击任一箱体可在主图高亮。
